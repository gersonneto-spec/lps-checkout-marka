# Gerador de Checkout LPS · Marka Engenharia

Página para montar a mensagem diária da Rotina LPS (checkout + programação) e copiar para o WhatsApp.

**Acesso:** https://gersonneto-spec.github.io/lps-checkout-marka/

## Uso diário
1. Lance o executado de cada atividade. Onde ficou abaixo do previsto, escolha o motivo.
2. Atualize avanço acumulado, restrições e a programação do dia seguinte.
3. Toque em **Copiar mensagem** e cole no grupo.
4. No fim, toque em **Fechar o dia** para preparar o checkout seguinte.

Os dados ficam salvos só no navegador de quem usa a página. Use sempre o mesmo aparelho e o mesmo navegador.
